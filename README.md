# 🚗 Sistema de Controle de Alunos de Autoescola

Este projeto foi desenvolvido com o objetivo de auxiliar no gerenciamento de alunos em uma autoescola, permitindo o controle simples e eficiente das informações.

## 💻 Funcionalidades

* Cadastro de alunos
* Listagem de alunos
* Controle de status (Em andamento, Aprovado, Reprovado)
* Remoção de alunos

## 🛠️ Tecnologias utilizadas

* HTML
* CSS
* JavaScript

## 🚀 Objetivo do projeto

Este sistema foi criado como parte do meu aprendizado em desenvolvimento web, com foco na resolução de problemas reais do dia a dia profissional.

## 📌 Aplicação prática

O projeto é baseado na minha experiência como instrutor de trânsito, facilitando o acompanhamento e organização dos alunos.
